# Egress the sandbox may reach at runtime. One host per line; `#` starts a
# comment. Everything not listed here is denied.
#
# This file is the readable mirror of network-policy@2 runtime.allow. The
# normative copy lives in kit/t3-code.yaml because a Kit carries its authority
# in the image, under one digest — policy that lives outside the artifact can
# drift from it. `npm run smoke` fails if the two disagree.
#
# Install-time egress is a different list with a different meaning, and lives
# in policy/install.txt. Do not merge the two: `npm run policy` prints
# *this* file as "egress allowed at runtime", so a build-time host here reads
# as a runtime permission an agent will then act on.
#
# ⚠️ A missing host does not look like a network error. The proxy answers
# HTTP 403 with "Approval required for <host:port>", so an agent that "cannot
# reach the API" is usually a missing line here.

# --- model providers: pi's endpoint, plus the two you are most likely to add
api.anthropic.com
api.openai.com
api.mistral.ai

# --- git: clone and push only
github.com
api.github.com
codeload.github.com
objects.githubusercontent.com

# --- model catalogs. t3 fetches its model manifest from raw.githubusercontent,
# and pi checks its own catalog on pi.dev. Without these the model list is the
# stale one bundled in the image.
raw.githubusercontent.com
pi.dev

# --- t3's agent icons. t3 renders one icon per agent it can drive and fetches
# it from the Agent Client Protocol (ACP) registry CDN. Cosmetic: denied, the
# UI just shows no icon.
# t3 validates the URL against this exact hostname, so a mirror or a vendored
# copy is not a substitute.
cdn.agentclientprotocol.com

# --- package installs inside the sandbox
registry.npmjs.org
